    sealed trait - тип интерфейса, который может быть расширен только в том же файле, в котором объявлен.
    implicit - неявный тип - позволяет преобразовать данное значение в новый тип, избегая ошибки компиляции.
    case class - класс-образец - используются для работы с неизменяемыми данными (например, настройки программы).
    object - класс-объект - альтернатива синглтону, создаёт единственный на всю программу экземпляр класса.
    Either[type1, type2] - алгебраический тип "или-или". Имеет два исхода событий:
Left(type1) - плохой и Right(type2) - хороший.
    .collect - комбинация фильтрациии и преобразования, применяет функцию лишь тем значениям, для которых
она определена.
    Unit - тип данных, возвращающий пустой кортеж. Можно сказать, что схож с void.
    .stripMargin - метод для работы с многострочными строками (multiline strings), заключенными в тройные
кавычки ("""...""").
    CLi - Commannd Line Interface.
